# Agentic Equity Market Analyst

A multi-agent AI application for equity market research,
financial analysis, risk assessment and valuation.

## Initial development milestone

Market Data Agent:
- Retrieve historical stock prices
- Calculate daily simple and logarithmic returns
- Calculate cumulative returns and volatility
- Generate interactive price and return charts

## Technology

Python, LangGraph, Pandas, NumPy, Plotly and FastAPI (planned).
